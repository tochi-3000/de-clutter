Declutter — Architecture Blueprint

Component modularization, client-server RPC bridge, concurrency control, and deterministic disaster recovery.

System Architecture & Data Flow

Config.js
Central configuration: 270s watchdog limit, 100 search chunk size, 50 batch trash size, 6k row threshold rotation cap.
Implements: Constants & Limits
LockManager.js
Wraps LockService.getUserLock() with 10s acquisition timeout to prevent race conditions between cron and manual runs.
Implements: Mutex Concurrency Guard
QueryCompiler.js
Tokenizes keywords, preserves quoted phrases (e.g., "verification code"), sanitizes operator breakouts, and appends safety clauses.
Implements: Injection Firewall
ExecutionEngine.js
Coordinates watchdog loop, executes 100-thread chunk queries, tags Declutter/Trashed-RunID, and batches trash mutations.
Implements: Batch Processing Pipeline
RollbackManager.js
Queries trashed threads by session label, restores them via moveThreadsFromTrash(), deletes label, and logs RESTORED.
Implements: 1-Click Disaster Recovery
SheetStore.js
Manages spreadsheet I/O, flushes buffered logs in a single setValues() call, and executes 1,000-row batch pruning at 6k rows.
Implements: Relational Storage & Rotation
Sidebar.html
Self-contained embedded UI with Gmail-native styling, auto dark/light theme, and Promise-wrapped RPC client.
Implements: Non-Developer GUI
Code.js
Container entry point: creates custom menu, launches sidebar, and exposes secure RPC endpoints.
Implements: API Dispatcher
Failure Scenario Trigger Condition Fallback & User Feedback
Lock Contention Manual run clicked while scheduled cron trigger is running Lock acquisition times out after 10s. Clean abort: "Another Declutter process is currently running. Please try again shortly."
Watchdog Limit Hit Execution duration exceeds 270,000 ms (4.5 mins) Search chunker loop terminates, flushes all buffered logs to Sheet in single batch call, and cleanly exits. Remainder picks up next day.
Zero Email Matches No inbox threads match rule filters Zero empty labels or bogus log rows created. Sidebar displays: "No matching emails found. Please adjust filters and try again."
Undo Without Prior Run User clicks Undo when no run exists or was already undone Rollback skipped cleanly. Sidebar displays: "No existing run".
Malformed Rule Input Blank sender pattern or negative retention days Rule row skipped with logged validation error; engine continues processing remaining valid rules.

Rules Sheet Schema

RuleID (String) | SenderPattern (String) | Keywords (String) | RetentionDays (Integer $\ge 1$) | ProtectStarred (Boolean) | DryRun (Boolean) | Status (ACTIVE / PAUSED)

Logs Sheet Schema

Timestamp (ISO-8601) | RunID (String) | RuleID (String) | Sender (String) | Subject (String) | ReceivedDate (ISO-8601) | ThreadID (String) | Mode (DRY_RUN / LIVE) | Action (WOULD_TRASH / TRASHED / RESTORED)
